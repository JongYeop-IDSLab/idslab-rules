# IDS Lab 연구실 수칙 · 근태 페이지

성균관대 IDS Lab 운영 수칙 공지 페이지와 출근·벌금 현황 페이지입니다.
정적 페이지는 GitHub Pages, 근태 데이터는 Google 스프레드시트 + Apps Script로 굴러갑니다.

```
index.html            수칙 공지 (8/31 시행)
attendance.html       출근 체크 · 이번 달 지각/벌금 현황
style.css             두 페이지 공용 스타일
apps-script/Code.gs   구글 시트 백엔드 (웹 앱으로 배포)
apps-script/fine_test.js  벌금 계산 로직 테스트 (node로 실행)
```

---

## 1. GitHub Pages 올리기

GitHub 웹에서 **New repository** → 이름 `idslab-rules` → **Public** → *Add a README 체크 해제* → Create.

그다음 이 폴더에서:

```bash
git init
git add .
git commit -m "IDS Lab 수칙 · 근태 페이지"
git branch -M main
git remote add origin https://github.com/<GITHUB_ID>/idslab-rules.git
git push -u origin main
```

레포 **Settings → Pages** → Source를 **Deploy from a branch**, 브랜치 `main` / `(root)` 로 저장.
1~2분 뒤 아래 주소가 열립니다.

```
https://<GITHUB_ID>.github.io/idslab-rules/
```

> 수칙만 먼저 공지하고 근태는 나중에 붙여도 됩니다. 이 상태로도 index.html은 완전히 동작합니다.

## 2. 근태 백엔드 붙이기 (구글 시트)

**(1) 시트 만들기**
[sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 `IDS Lab 근태`로 바꿉니다.

**(2) 스크립트 붙여넣기**
시트 상단 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 `apps-script/Code.gs` 내용을 통째로 붙여넣고 저장.

**(3) 시트 초기화**
편집기 상단 함수 목록에서 `setupSheets` 를 고르고 **실행**. 권한 승인 창이 뜨면 허용합니다.
(“이 앱은 확인되지 않았습니다” → *고급* → *이동*)
`설정` · `구성원` · `근태기록` 세 시트가 생깁니다.

**(4) 구성원 채우기**
`구성원` 시트에 랩원 이름을 한 줄씩 적습니다. 활성 열은 `Y`, 나간 사람은 `N`으로 두면 목록에서 빠집니다.

**(5) 웹 앱으로 배포**
편집기 우측 상단 **배포 → 새 배포** → 유형 `웹 앱`

| 항목 | 값 |
|---|---|
| 실행 계정 | **나** |
| 액세스 권한 | **모든 사용자** |

배포하면 `https://script.google.com/macros/s/AKfycb.../exec` 주소가 나옵니다. 복사해 두세요.

**(6) 페이지에 연결**
`attendance.html` 안의 이 줄에 붙여넣고 다시 push 합니다.

```js
var API_URL = "";   // ← 여기에 /exec 주소
```

```bash
git add attendance.html && git commit -m "근태 API 연결" && git push
```

## 설정 바꾸기

코드를 고칠 필요 없이 `설정` 시트의 값만 바꾸면 바로 반영됩니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| 코어타임시작 | `10:00` | 이 시각을 넘겨 체크하면 지각 |
| 벌금시작일 | `2026-09-14` | 이 날짜부터 벌금 부과 |
| 기본벌금 | `10000` | 그 달 첫 지각 금액 |
| 인상액 | `5000` | 지각 1회마다 인상되는 금액 |
| 회당상한 | `30000` | 1회 지각의 최대 금액 |
| 재택_월한도 | `3` | 월 재택 사용 가능 횟수 |
| 재택_주한도 | `1` | 주 재택 사용 가능 횟수 |

**벌금 계산** — 그 달 n번째 지각은 `min(기본벌금 + 인상액 × (n−1), 회당상한)`,
월 납부액은 그 달 지각들의 합계입니다. 매월 1일에 자동으로 초기화됩니다(별도 조작 불필요).

| 지각 횟수 | 이번 지각 | 월 누적 |
|---|---|---|
| 1회차 | 10,000원 | 10,000원 |
| 2회차 | 15,000원 | 25,000원 |
| 3회차 | 20,000원 | 45,000원 |
| 4회차 | 25,000원 | 70,000원 |
| 5회차 | 30,000원 | 100,000원 |

## 관리 팁

- **기록 수정** — `근태기록` 시트에서 직접 고치면 됩니다. 페이지는 시트를 그대로 읽습니다.
- **지각 면제** — 해당 행의 `비고` 열에 `면제` 라는 글자를 넣으면 벌금 계산에서 빠집니다. (수업, 외부 일정 등)
- **주말·공휴일** — 주말은 자동으로 지각 판정을 하지 않습니다. 공휴일은 `비고`에 `면제`로 처리해 주세요.
- **중복 체크 방지** — 하루에 한 번만 기록됩니다. 두 번째 시도는 거절되고 기존 기록을 알려 줍니다.
- **코드 수정 후** — Apps Script를 고쳤으면 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로입니다.
